# Token audit, 2026-10-10

Full numbers: the project file `claude-setup/tokens/2026-10-10.md` (122 sessions, from `get_session` usage totals).

## What it shows

- A fresh thread's first request is about 108k to 110k tokens (two samples). Reads of that context are half the bill, writes of new context 37%.
- The repo owns only about 6.4k of it (`2026-10-07.md`): CLAUDE.md, the three always-on rules, skill and agent listings, plugins. Rules for languages are path-scoped. Nothing left here is worth another cut.
- The other 100k sits in the project and harness: system prompt and tool schemas (not measurable from a thread), the CLAUDE.md of every repo in the project's list (duo-test 2.7k, mypage 0.7k), the MEMORY.md index (3.7k), the project files list (about 3k), plugin and account skill lists.
- Google connectors cost about 0.8k (tool names only, schemas deferred). Not a lever.

## Rules that follow

- A repo that is done or parked leaves the project's repo list; its CLAUDE.md loads in every thread otherwise.
- MEMORY.md stays under 8 KB; history goes to topic files, not the index.
- Big binary or screenshot folders in the project files go into one archive zip once their thread is closed; the file list loads in every thread.
- Fable and effort above medium only where the work needs them: Fable 5.1 cache read is $0.25/M, 1.25x Opus 5.5 ($0.20), not 2.2x (anthropic.com/pricing, 2026-10-17); Haiku 5.5 cache read is $0.01 up to 100k prompt, $0.05 above; max effort adds output.
- A real `/context` run in a fresh thread on the PC is the only way to see the harness part; do it before cutting further.

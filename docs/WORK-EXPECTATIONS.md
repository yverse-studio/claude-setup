# Work expectations

The standing explanation of how yskills' adult-game work is done. It applies to every repo,
project and chat he starts, wherever character, 3D model, scene or story work for his adult games
comes up. Read it and the project memory first and do not re-ask what it settles. The public
files stay clean: explicit material is private, behind the 18+ gate, and never goes in a public
repo.

## For any project

**Cast.** Every character is an original adult fictional character: inspired by, not a copy of.
Every character has an adult age stated in the text, and the player is an adult. No minors ever,
in any form. Family cameos stay non-sexual.

**References are the target.** yskills' references (uploaded images and videos; clips in the
style of blobcg, Being a DIK and paradise-girls) set the look, quality and motion to reach. Match
them 1:1 with the compare-first loop: his reference on the left, our model on the right, judged
per trait (5 traits). The bare body comes first and is made perfect before anything else.

**Reusable by design.** Models and scenes are built to be reused: a library of characters,
clothes and poses, plus a repeatable character-creator workflow, ideally usable without AI.
General steps: `docs/character-workflow.md`.

**Decide, then deliver.** One clear default instead of asking; say which. Every thread reviews
its own work and reports only at 5/5.

**What finished looks like.** It matches the reference per trait, nothing clips or floats, it
moves naturally, it renders cleanly under the project's lights, and it is stored where the
library finds it. A trait below 5/5 is not finished.

**Content line.** Explicit material stays private behind the 18+ gate. Public files, docs and
code stay clean.

# Token diet, 2026-10-07

Goal: fewer tokens per session; we keep hitting the session limit.

## Measurement

`/context` is a slash command of the interactive CLI; a cloud thread has no tool to run it. So
this is a static count of what claude-setup puts into every session: bytes / 4 of CLAUDE.md,
the always-on `common` rules (language rules are path-scoped and load only on matching files),
the name + description of every skill and agent (the listing the model sees each turn), and the
always-on plugin costs from `config/plugins.json`. A project thread's own base (system prompt,
tools, memory, project instructions, ~114k at start) is outside this repo and is not counted.
yskills can compare with a real `/context` run in a fresh thread.

| Item (tokens, est.) | Before | After |
|---|---|---|
| CLAUDE.md | 2461 | 2369 |
| common rules | 1181 | 1181 |
| skill listing (33 skills) | 2589 | 1176 |
| agent listing (19 agents) | 1262 | 545 |
| global plugins | 1763 | 1139 |
| **Total** | **9256** | **6410 (-31%)** |

Target: -30% of the repo-owned always-on load. Result: -31%.

## Cuts

- Skill and agent descriptions rewritten to one short line each (the long ones were 300-500 chars).
  The vendored ECC skills will get their old text back on the next `node scripts/sync-ecc.mjs`;
  re-trim then.
- Plugins `claude-code-setup`, `claude-md-management`, `feature-dev`, `code-simplifier` moved from
  global to retired (installer turns them off; add per project when needed). `cloud/setup.sh`
  re-paste needed in the cloud environment.
- CLAUDE.md: the false "output is 2%, terse output doesn't help" line replaced by the real split
  (output is about 50% of the bill on Sonnet, 67% on Opus, per
  `docs/research/2026-10-07-own-local-model.md`); agent list dropped (the session lists them).
- Models table: simple reading jobs go to a Haiku subagent.
- Context guard: absolute floors, warn at 150k, hand off at 200k, repeats every further 50k.

## Not cut

Common rules (small), path-scoped language rules (load only on matching files), skills that
other skills name (operator, researcher). Project instructions: see `project-instructions.md`.

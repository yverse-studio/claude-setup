## Patterns behind the rows

- **A state is not a signal.** Rows 2, 3. Work waits until someone polls; a handoff needs a line that names the next owner.
- **The coordinator loses its own rules at every recycle.** Rows 1, 4, 5. The persona, the mandate and the plan mapping need to sit in the first lines it reads, and be checked per post.
- **Format rules checked late cost round trips.** Rows 6, 7. A generator and a full-list refusal replace trial and error.
- **The gate measured the easy part again.** Rows 9, 10 (same pattern as rows 1 and 2 of `docs/LESSONS-2026-11-12.md`).

## Not fixed here

- The host does not wake the coordinator on `review_ready`; that is outside this repo. Row 2 is the workaround.
- Remote Control sessions cannot message threads. Row 3 only makes parking visible.
- Each row needs its own small PR with a test or a guard; this file is the list they cite.

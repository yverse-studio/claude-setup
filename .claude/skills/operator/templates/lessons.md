# Lessons

The `docs/LESSONS.md` of a product repo. A lesson is written only when the next thread would
repeat the mistake without it. Update the line that covers it, never duplicate. A mechanical
lesson (a banned call, a file rule, a number) becomes a check in CI, not a line here.

Entry format, newest last:

- YYYY-MM-DD (<PR or thread>): <lesson>

A lesson true for every project goes to claude-setup (`docs/MAP.md`, Where a lesson goes), not here.

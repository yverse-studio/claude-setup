# music2: CC0 music beds (2026-10-26)

Found via the Openverse API (license=cc0,pdm), all hosted on Freesound. Each track's Freesound
page was saved to proof/<slug>.html and kept only if that page links the CC0 1.0 licence.
Files are the Freesound high-quality MP3 previews that Openverse links to.

Skipped: eliot-beats "Funk Beat" and FusionWolf3740 "Epic Music loop" (their Freesound pages
no longer show CC0), TheoTer "Big Band Jazz" (the page did not load).
